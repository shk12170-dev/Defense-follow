- 측정 중 정정: "목록 열람 없는 업무"를 처음엔 목록→검색 대체로 모델링해 엄격 프로필이 76%나 막혔는데, 검색 건수가 다시 쌓이는 모델 오류여서 목록 이벤트를 제거하는 방식으로 고침. 쿼터 조회를 요청마다 여러 번 하면 오버헤드가 +3%→+7.5%로 늘어 쿼리를 한 번으로 합침(최종 약 +5%).
- 테스트 16개 추가(총 179개). 기존 테스트가 R1 발동 흐름을 쓰므로 conftest에서 유형별 한도·재인증 후 축소는 기본으로 끄고 전용 테스트에서만 켬.
