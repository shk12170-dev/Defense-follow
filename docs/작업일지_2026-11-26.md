## 3차 보완 3: 단계적 재인증(step-up)
- `app/totp.py`(RFC 6238 TOTP, 표준 라이브러리), `users.stepup_required/totp_secret`(기존 DB 마이그레이션), `POST /auth/stepup`(코드+사유, 10분 3회 실패 시 잠금), 미통과 시 데이터 요청 428.
- R1·R5·R8은 `response: stepup`. R1은 재인증 후 창 초기화 + 24시간 내 재발동 시 잠금(`escalate_min`), R5·R8은 반복해도 잠그지 않음(R6 담당).
- 결과(합성 30일): 계정 잠금 오탐 1건 → 0건(R1 재인증 요구 1건), R5 재인증 요구 7건. 트레이드오프: 유효한 코드를 가진 내부자는 통과 가능, R1 기준 유출 최대 약 600건. 대시보드에 "재인증 대기" 패널, Kibana 저장된 검색 추가.
- 기존 테스트 중 "R1 → 즉시 잠금"을 가정한 것들을 새 동작에 맞게 수정하고, 재인증 테스트 11개 추가(총 120개). RFC 6238 테스트 벡터로 TOTP 검증.
